# Casos de Uso — Nexus Business Manager

O Nexus Business Manager é um ERP SaaS versátil que atende diversos segmentos. Abaixo, exemplos reais de aplicação.

---

## 1. Comércio Varejista

**Perfil**: Loja de roupas com 2 filiais

| Módulo      | Utilização |
|-------------|------------|
| Produtos    | Cadastro com SKU, categorias (masculino, feminino, infantil), preços |
| Estoque     | Entrada de fornecedor, saída por venda, alerta de estoque baixo |
| Vendas      | PDV integrado com baixa automática de estoque |
| Clientes    | CRM com histórico de compras e preferências |
| Financeiro  | Contas a pagar (fornecedores), a receber (parcelas), fluxo de caixa |
| Relatórios  | Exportação de vendas do dia/mês em PDF e Excel |

**Diferencial**: A multiempresa permite gerenciar as duas filiais separadamente com um único login.

---

## 2. Assistência Técnica

**Perfil**: Oficina de celulares e computadores

| Módulo      | Utilização |
|-------------|------------|
| Clientes    | Cadastro com telefone e endereço para contato |
| Produtos    | Peças de reposição (telas, baterias, conectores) com controle de estoque |
| Estoque     | Saída de peças por serviço realizado |
| Agendamentos| Calendário de serviços agendados por cliente |
| Vendas      | Ordem de serviço convertida em venda com mão de obra + peças |
| Notificações| Alerta de estoque baixo de peças críticas |

**Diferencial**: Agendamento evita acúmulo de serviços e organiza a fila de atendimento.

---

## 3. Escritório de Contabilidade

**Perfil**: Escritório com 5 colaboradores

| Módulo      | Utilização |
|-------------|------------|
| Usuários    | Perfis com permissões (admin, manager, operador, visualizador) |
| Clientes    | Carteira de clientes pessoa física e jurídica |
| Financeiro  | Controle de honorários mensais, despesas do escritório |
| Dashboard   | Indicadores de clientes ativos, receita recorrente, inadimplência |
| Relatórios  | Extratos financeiros por período |
| Auditoria   | Registro de todas as alterações em dados sensíveis |

**Diferencial**: Hierarquia de permissões garante que apenas administradores acessem dados financeiros.

---

## 4. Prestador de Serviços

**Perfil**: Fotógrafo profissional

| Módulo      | Utilização |
|-------------|------------|
| Clientes    | Cadastro com evento, data, local |
| Agendamentos| Ensaios marcados com data, horário e local |
| Financeiro  | Orçamentos, recebimentos, despesas de equipamento |
| Produtos    | Álbuns e pacotes de fotos |
| Vendas      | Fechamento de pacotes com desconto |
| Notificações| Lembrete de ensaio agendado para o dia seguinte |

**Diferencial**: Fluxo completo do orçamento ao recebimento, com agendamento integrado.

---

## 5. Distribuidora de Alimentos

**Perfil**: Distribuidora com 200+ produtos

| Módulo      | Utilização |
|-------------|------------|
| Produtos    | Categorias (mercearia, bebidas, limpeza), controle de lote |
| Estoque     | Movimentações de entrada (compra) e saída (venda) |
| Fornecedores| Cadastro com contato comercial |
| Compras     | Pedidos com múltiplos itens, recebimento parcial |
| Vendas      | Pedidos de clientes com itens e valores |
| Financeiro  | Contas a pagar (fornecedores), a receber (clientes), fluxo de caixa |
| Dashboard   | Faturamento mensal, produtos mais vendidos, estoque baixo |

**Diferencial**: Compras com múltiplos itens e recebimento facilitam a reposição de grandes lotes.
