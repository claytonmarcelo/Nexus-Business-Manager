# Requisitos — Nexus Business Manager

## Funcionais

- RF01 — Autenticação com JWT (login, cadastro, recuperação de senha)
- RF02 — Gerenciamento de usuários com papéis (admin, manager, user)
- RF03 — Dashboard com indicadores e gráficos
- RF04 — CRM para gestão de clientes
- RF05 — Controle de estoque com entradas e saídas
- RF06 — Gestão financeira (receitas, despesas, fluxo de caixa)
- RF07 — Agendamento de serviços e eventos
- RF08 — Relatórios exportáveis
- RF09 — Multitenancy (SaaS)

## Não Funcionais

- RNF01 — API RESTful com respostas padronizadas
- RNF02 — Autenticação segura via JWT
- RNF03 — TypeScript em toda a base
- RNF04 — Banco de dados relacional MySQL
- RNF05 — Código modular e escalável
