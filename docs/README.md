# Documentação do Nexus Business Manager

Índice do que existe nesta pasta. O código conta o que faz; aqui fica o estado, a escolha e a prova.

| Arquivo | O que responde |
|---|---|
| [`ESTADO-ATUAL.md`](ESTADO-ATUAL.md) | O que a instalação tem hoje, medido: rotas, migrations, testes, cobertura e os efeitos colaterais conhecidos |
| [`AUDITORIA.md`](AUDITORIA.md) | Todo achado da auditoria comercial, numerado (N..), com a situação de cada um |
| [`STATUS-AJUSTES.md`](STATUS-AJUSTES.md) | Tarefa por tarefa: o que foi feito, com qual evidência e em qual commit |
| [`PRODUCAO.md`](PRODUCAO.md) | Subida real: container, variáveis obrigatórias, backup e primeira configuração |
| [`adr/`](adr/) | Decisões de arquitetura, uma por arquivo, com o motivo e o que foi recusado |
| [`decisoes/`](decisoes/) | Decisões que são do dono (e-mail, cobrança, fiscal, licença, hospedagem, administrador da plataforma) |
| [`design/`](design/) | Fundamentos visuais e de arquitetura que as telas seguem |
| [`screenshots/`](screenshots/) | Capturas de prova, do banco de demonstração, revisadas uma a uma |
| [`ANALISE.md`](ANALISE.md) e [`ANALISE-LACUNAS.md`](ANALISE-LACUNAS.md) | A leitura inicial do pedido e o que faltava nela |

Como conferir uma afirmação daqui: o comando executado está escrito junto do número, na coluna de evidência de `STATUS-AJUSTES.md`. O que não tem comando rodado está marcado `NÃO VERIFICADO`.
