# Use Cases — Nexus Business Manager

Nexus Business Manager is a versatile SaaS ERP that serves various business segments. Below are real-world application examples.

---

## 1. Retail Store

**Profile**: Clothing store with 2 branches

| Module       | Usage |
|--------------|-------|
| Products     | SKU-based catalog, categories (men, women, kids), pricing |
| Inventory    | Supplier inbound, sales outbound, low-stock alerts |
| Sales        | POS integration with automatic stock deduction |
| Clients      | CRM with purchase history and preferences |
| Financial    | Accounts payable (suppliers), receivable (installments), cash flow |
| Reports      | Daily/monthly sales export in PDF and Excel |

**Differentiator**: Multi-company support lets you manage both branches separately with a single login.

---

## 2. Tech Repair Shop

**Profile**: Cellphone and computer repair shop

| Module       | Usage |
|--------------|-------|
| Clients      | Contact registration with phone and address |
| Products     | Spare parts (screens, batteries, connectors) with stock control |
| Inventory    | Part deduction per completed service |
| Appointments | Service calendar scheduled by client |
| Sales        | Work order converted to sale with labor + parts |
| Notifications| Low-stock alerts for critical parts |

**Differentiator**: Scheduling prevents service backlog and organizes the service queue.

---

## 3. Accounting Office

**Profile**: Office with 5 employees

| Module       | Usage |
|--------------|-------|
| Users        | Role-based permissions (admin, manager, operator, viewer) |
| Clients      | Individual and corporate client portfolio |
| Financial    | Monthly fee control, office expenses |
| Dashboard    | Active clients, recurring revenue, delinquency KPIs |
| Reports      | Financial statements by period |
| Audit        | Log of all changes to sensitive data |

**Differentiator**: Role hierarchy ensures only administrators access financial data.

---

## 4. Service Provider

**Profile**: Professional photographer

| Module       | Usage |
|--------------|-------|
| Clients      | Registration with event, date, location |
| Appointments | Scheduled shoots with date, time, location |
| Financial    | Quotes, payments, equipment expenses |
| Products     | Albums and photo packages |
| Sales        | Package closing with discounts |
| Notifications| Reminder of next day's scheduled shoot |

**Differentiator**: Complete flow from quote to payment, with integrated scheduling.

---

## 5. Food Distributor

**Profile**: Distributor with 200+ products

| Module       | Usage |
|--------------|-------|
| Products     | Categories (groceries, beverages, cleaning), batch control |
| Inventory    | Inbound (purchase) and outbound (sale) movements |
| Suppliers    | Registration with commercial contact |
| Purchases    | Multi-item orders, partial receiving |
| Sales        | Customer orders with items and values |
| Financial    | Accounts payable (suppliers), receivable (clients), cash flow |
| Dashboard    | Monthly revenue, top-selling products, low stock |

**Differentiator**: Multi-item purchases with partial receiving simplify large-batch replenishment.
