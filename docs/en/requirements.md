# Requirements — Nexus Business Manager

## Functional

- FR01 — JWT authentication (login, registration, password recovery)
- FR02 — User management with roles (admin, manager, user)
- FR03 — Dashboard with KPIs and charts
- FR04 — CRM for client management
- FR05 — Inventory control with stock in and stock out
- FR06 — Financial management (revenue, expenses, cash flow)
- FR07 — Service and event scheduling
- FR08 — Exportable reports
- FR09 — Multi-tenancy (SaaS)

## Non-Functional

- NFR01 — RESTful API with standardized responses
- NFR02 — Secure authentication via JWT
- NFR03 — TypeScript throughout the codebase
- NFR04 — MySQL relational database
- NFR05 — Modular and scalable code
