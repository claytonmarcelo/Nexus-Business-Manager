# Capturas de Tela — Nexus Business Manager

Esta pasta deve conter capturas de tela do sistema em funcionamento.

## Como gerar

1. Inicie o backend: `cd backend && npm run dev`
2. Inicie o frontend: `cd frontend && npm run dev`
3. Acesse `http://localhost:5173`
4. Faça login com `admin@nexusdemo.com` / `123456`
5. Capture as telas abaixo:

## Telas para capturar

| Screenshot          | Descrição                          |
|---------------------|------------------------------------|
| `login.png`         | Tela de login com formulário       |
| `dashboard.png`     | Dashboard com indicadores e gráficos |
| `clients.png`       | Lista de clientes com busca        |
| `products.png`      | Lista de produtos                  |
| `stock.png`         | Movimentações de estoque           |
| `suppliers.png`     | Lista de fornecedores              |
| `purchases.png`     | Compras realizadas                 |
| `sales.png`         | Vendas registradas                 |
| `financial.png`     | Fluxo de caixa                     |
| `appointments.png`  | Calendário de agendamentos         |
| `reports.png`       | Relatórios disponíveis             |
| `settings.png`      | Configurações / empresas           |

## Ferramentas recomendadas

- **Windows**: Recorte e Esboço (Win + Shift + S)
- **macOS**: Cmd + Shift + 4
- **Linux**: Flameshot ou GNOME Screenshot
- **Extensão Chrome**: GoFullPage (para capturas de página inteira)
