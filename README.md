# Nexus Business Manager

ERP SaaS moderno para gestão empresarial completa.

## Descrição

O Nexus Business Manager é um sistema planejado para centralizar os principais processos de uma empresa em uma única plataforma moderna, escalável e preparada para SaaS.

## Módulos Planejados

- Dashboard Executivo
- CRM
- Estoque
- Financeiro
- Agendamento
- Relatórios
- Usuários e Permissões
- Configurações do Sistema
- Multiempresa

## Tecnologias Planejadas

### Backend
- Node.js
- Fastify
- TypeScript
- JWT
- MySQL

### Mobile
- React Native
- TypeScript

### Web
- React
- TypeScript
